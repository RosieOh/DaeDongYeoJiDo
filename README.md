# 대동여지도

대한민국의 관광지를 실제 좌표와 입체 지형으로 탐색하는 반응형 웹앱입니다. 무협 게임의 두루마리 세계지도에서 영감을 받은 수묵 청록산수 지도(한지 바탕, 물결무늬 바다, 먹 음영과 석청·석록 산세, 붓글씨 지명, 낙관과 윤도 나침반, 흐르는 구름), 직접 제작한 산·길·해 로고와 Pretendard·나눔명조·나눔손글씨 붓을 사용합니다. 지도 탐험 외에 직접 캐릭터를 조작하는 3인칭 여행 시뮬레이션을 제공합니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm install
npm run dev
```

개발 서버: http://127.0.0.1:5173

```sh
npm run build    # TypeScript 검사 + 배포용 dist 생성
npm run preview  # 빌드 결과 확인
npm test         # 검색·필터·GIS 좌표·충돌·12개 공간 무결성·지형·전통 건축·경공 이동 검사
```

Chrome이 설치되어 있고 개발 서버가 실행 중인 환경에서는 `node scripts/browser-check.mjs`로 실제 지도 렌더링, 카메라 이동, 검색, 저장 유지, 테마·지역 필터, 모바일 상세 화면을 검증할 수 있습니다. `node scripts/journey-check.mjs`는 실제 캐릭터 이동, 경공 도약·착지, 명소 발견·저장, 일시정지, 노을, 사진 다운로드, 여행지 전환, 모바일 조이스틱과 지도 복귀를 검증합니다. 서버 포트가 다르면 `BASE_URL=http://127.0.0.1:5174 node scripts/journey-check.mjs`처럼 지정하세요. 검증 스크린샷은 시스템 임시 디렉토리에 생성됩니다.

## 여행 시뮬레이션

상단 **여행 시뮬레이션** 메뉴 또는 관광지 상세정보의 **이곳에서 가상 여행 시작** 버튼으로 들어갑니다. 직접 주소는 `/#/journey/jeonju`이며 마지막 경로를 관광지 ID로 바꿀 수 있습니다. 브라우저 뒤로 가기와 직접 새로고침을 지원합니다.

- WASD / 방향키: 캐릭터 이동
- Shift: 달리기
- Space: 도약. 세 번까지 연달아 뛰어오르고(두 번째는 앞공중제비, 세 번째는 나선 회전), 누르고 있으면 활공합니다. 활공 중에 방향을 틀면 몸과 카메라가 기웁니다.
- F 또는 1: 비연. 바라보는 방향으로 순식간에 몸을 날립니다. 공중에서 Shift를 새로 눌러도 됩니다.
- Q 또는 2: 제운종. 나선을 그리며 하늘 높이 솟구친 뒤 바람을 타고 활공합니다.
- C 또는 3: 천근추. 공중에서 내리꽂혀 충격파와 흙먼지를 일으킵니다.
- 벽호공(자동): 공중이나 질주 중에 벽·지붕·절벽으로 달려들면 벽을 타고 올라 넘어섭니다. 벽을 타는 중 Space를 누르면 벽을 차고 뛰어오릅니다.
- 능파보: 질주하거나 뛰어서 물에 내려서면 수면 위를 달립니다.
- 경공은 기력을 쓰고 땅에서 회복합니다. 하늘에 머문 시간만큼 경공 경지(입문→소성→대성→화경→현경)가 오르며 브라우저에 저장됩니다.
- 마우스 또는 화면 드래그: 카메라 회전
- 휠: 카메라 거리 조절
- E / 둘러보기 버튼: 가까운 명소 발견 및 여행 수첩 기록
- Escape: 일시정지 또는 열린 정보 닫기
- 모바일: 조이스틱 이동, 경공 버튼(누르면 도약, 누르고 있으면 활공), 질주 버튼, 오른쪽 비연·제운종·천근추 버튼, 화면 드래그
- 상단 도구: 낮 → 노을 → 달밤 전환, 풍경 PNG 저장, 조작 안내

현재 등록된 **12개 관광지 모두**에 지역별 실제 GIS 공간을 적용했습니다. 공통 가상 마을 대신 OpenFreeMap/OSM의 건물 윤곽, 도로 중심선, 수계, POI와 Terrain Tiles의 고도 격자를 사용합니다. 각 장소는 중심 주위 약 **900 × 900m**를 걸을 수 있으며, 주변 지형은 **1.8 × 1.8km**까지 표시합니다. 미니맵과 캐릭터 위치는 같은 좌표계를 사용하고 이동 거리는 실제 미터 단위입니다.

실제 지도에 맞춘 배치 위에 전통 건축과 자연을 절차적으로 생성합니다. **외관, 도로 폭, 수목 위치는 추정 표현**이며 건물 높이도 기본값일 수 있습니다. 사진측량 모델이나 실측 디지털 트윈은 아닙니다. 원본 게임 자산은 사용하지 않습니다. 건물 윤곽·수계·담장 충돌, 지형을 따라 걷기, 따라오는 카메라, 낮·노을·달밤, 사진 저장, 실제 주변 미니맵을 구현했습니다. 수변 높이는 보정되어 실제와 다를 수 있습니다.

### 여행 공간 그래픽

무협 MMORPG의 산수화 같은 화면을 참고해 웹에서 구현한 연출입니다. 모든 모델과 셰이더는 이 프로젝트에서 직접 작성했습니다.

- **빛과 대기**: 물리 기반 하늘 돔(구름·태양·달·별)과 같은 하늘에서 구운 환경광, 높이 안개와 골짜기 물안개, 태양 빛줄기, GTAO 앰비언트 오클루전, 블룸, 필름 톤매핑과 색보정
- **지형**: 원본 고도를 Catmull-Rom 보간해 약 4m 격자로 세분하고 잔디·흙·바위·모래·낙엽·마사토를 경사와 토지 피복에 따라 섞습니다. 주변 약 29 × 29km의 실제 산줄기와 해안을 원경으로 표시합니다.
- **전통 건축**: OSM 건물 윤곽을 직사각형 칸으로 나눠 팔작·맞배·우진각·초가지붕을 올립니다. 처마 곡선(앙곡·안허리), 기와, 막새, 서까래, 용마루·추녀마루, 궁궐의 양성바름·취두·잡상, 기둥·창방·공포와 단청, 창호, 장대석 기단과 계단, 중층 전각을 표현하며 가까운 건물에는 세부 목구조를 스트리밍합니다. 전주·하회마을 골목에는 기와 돌담이 이어집니다.
- **자연**: 바람에 흔들리는 소나무·활엽수·메타세쿼이아·관목, GPU 잔디, 들꽃 군락, 순천만 갈대밭, 바위, 보성 차밭 이랑, 꽃잎·낙엽, 밤의 반딧불, 하늘을 도는 학 무리. 먼 숲은 이어진 수관으로 표현합니다.
- **물과 구름**: 물가에서는 장면을 실시간으로 비추는 수면 반사(고품질), 물결과 프레넬 반사를 씁니다. 높은 산에서는 실제 주변 골짜기 고도를 따라 운해가 차오르고 봉우리가 그 위로 솟습니다.
- **인물**: 그린 얼굴(검미·눈매), 높이 묶은 긴 머리와 뒷머리, 자수를 놓은 비단 도포와 얇은 겉옷 자락, 넓은 소매, 옥 노리개, 등에 멘 검과 술을 갖춘 협객. 네 갈래 도포 자락과 소매, 머리카락, 띠는 천·끈 물리로 움직이며 다리와 몸통에 부딪히지 않습니다. 걷기·달리기·도약·공중제비·활공·착지 자세가 이어지고 달밤에는 등롱을 듭니다.
- **경공**: 3단 도약·활공·비연·제운종·천근추·벽호공·능파보와 기력, 재사용 대기시간. 기술마다 자세(앞공중제비, 나선 회전, 비행 자세, 벽 달리기, 착지 구르기)가 다르고, 잔상, 양 소매와 발끝의 빛 궤적, 기운 입자, 흙먼지, 물보라, 충격파, 카메라 흔들림과 기울기, 속도선과 방사형 흐림이 따라붙습니다.
- **게임 화면**: 여행 화면은 전체 화면으로 열리며 먹색 바탕에 금테를 두른 HUD를 씁니다. 초상화와 기력·수련 게이지, 원형 미니맵과 시각(午時·酉時·子時), 여행 수첩, 경공 단축창(재사용 대기 표시), 지역 진입 타이틀, 강호 소식 창, 머리 위 이름표와 기술 이름 붓글씨, 경공 비급(도움말)이 있습니다.
- **고도(古都) 연출**: 실제 건물 윤곽은 모두 전통 건축으로 그리고(배치와 길은 실제), 은행·벚꽃·단풍 가로수와 숲, 먼 산의 단풍·꽃 무리, 골목을 오가는 마을 사람, 골목 위 등롱 줄, 석등, 붓글씨 깃발, 물 위 나룻배를 둡니다.
- **장소별 연출**: 궁궐·사찰·한옥마을·초가 마을을 위치로 구분하고, 도담삼봉처럼 고도 격자보다 작은 상징 지형은 직접 모델링했습니다.
- **연출된 풍경**: 걷는 구역(약 900m) 밖의 산세를 최대 1.5~2.2배로 높여 원경을 극적으로 만들고, 먼 능선에 소나무가 자라는 기암 봉우리를 세웁니다. 설악산·도담삼봉에는 길에서 보이는 폭포와 소를, 길가 전망 지점과 물가에는 정자를 두고, 마을과 숲에는 대나무 숲, 궁궐·사찰 연못에는 연꽃을 그렸습니다. 달밤에는 강 위에 유등이 떠다니고 하늘로 풍등이 오릅니다. 위치와 길은 실제이며 이 요소들은 화면에 '산세와 풍경은 연출'로 표시합니다.
- **품질 단계**: 데스크톱은 고품질(MSAA, AO, 블룸, 4096 그림자, 잔디 11만 포기, 수면 반사), 터치 기기나 저사양 기기는 경량 모드(FXAA, 짧은 시야의 잔디, 2048 그림자, 반사 없음)로 실행합니다. 프레임이 계속 느리면 렌더 해상도를 자동으로 낮추고, 마을은 150m 구역으로 나눠 화면과 그림자 밖 구역을 건너뜁니다. 주소에 `?quality=low` 또는 `?quality=high`를 붙여 강제할 수 있습니다. 예: `/?quality=low#/journey/jeonju`

여행 수첩은 실제 POI 주변과 일반 탐방길의 최대 4개 지점을 기록합니다. 기록은 장소별로 브라우저에 저장하며 이전 가상 마을의 기록과 구분합니다. 일반 탐방길 이름은 공식 관광지 명칭이 아닙니다. 실제 현장 통행이나 입장 가능 여부를 보장하지 않습니다.

데이터의 원본 URL, 라이선스, 수집 시각과 변환 범위는 [GIS 출처 안내](public/geo/SOURCES.md)와 각 JSON의 `source`에 있습니다. 데이터 재생성은 Node.js 24 이상에서 `node scripts/build-geoscenes.mjs`로 실행합니다. 런타임에서는 로컬 스냅샷을 불러오므로 여행 공간을 위한 API 키가 필요하지 않습니다.

- `src/three/JourneyEngine.ts`: 렌더링, 키보드·터치 입력, 카메라, 시간대와 생명주기
- `src/three/post.ts`: AO·대기 원근·물안개·빛줄기·블룸·색보정 후처리
- `src/three/sky.ts`: 낮·노을·달밤 하늘과 환경광, 시간대별 연출 값
- `src/three/quality.ts`: 기기별 품질 단계와 공용 셰이더 유니폼

## 지도·사진·폰트 출처

지도는 [MapLibre](https://maplibre.org/maplibre-gl-js/docs/), [OpenFreeMap](https://openfreemap.org/quick_start/), [OpenStreetMap](https://www.openstreetmap.org/copyright), [Natural Earth](https://www.naturalearthdata.com/), [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)를 사용합니다. 지형 구성은 [MapLibre의 terrain 예제](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)를 참고했습니다. 경계 데이터는 Natural Earth의 공개 데이터입니다.

사진은 Wikimedia Commons에서 가져왔으며 각 원본의 라이선스가 적용됩니다. 앱의 왼쪽 하단 정보 버튼에서 개별 출처와 라이선스를 볼 수 있습니다. 사진은 화면에 맞게 잘라 표시합니다. 로고와 사진 로딩 실패 시 표시하는 일러스트는 이 프로젝트에서 제작했습니다.

[Pretendard](https://github.com/orioncactus/pretendard)는 로컬 가변 WOFF2 파일로 포함했습니다. SIL Open Font License 원문은 `public/fonts/OFL.txt`에 있습니다. 지도의 붓글씨와 명조체는 [나눔명조](https://fonts.google.com/specimen/Nanum+Myeongjo)와 [나눔손글씨 붓](https://fonts.google.com/specimen/Nanum+Brush+Script)(SIL OFL 1.1, `public/fonts/OFL-Nanum.txt`)을 Google Fonts의 글자 범위별 조각으로 받아 `public/fonts/nanum-*`에 두고 `src/fonts.css`에서 필요한 조각만 불러옵니다. 입체 모델과 여행 공간은 [Three.js](https://threejs.org/)로 직접 구성했습니다.

여행 공간의 지면·회벽·목재·수피 질감은 [ambientCG](https://ambientcg.com)의 CC0(퍼블릭 도메인) 자료를 512px로 줄여 사용합니다. 자료별 원본은 `public/textures/CREDITS.json`에 있습니다. 기와·단청·창호·초가·나뭇잎·물결 텍스처는 코드로 생성합니다.

## 현재 범위와 운영 시 고려사항

현재는 전국의 대표 여행지 12곳을 수동 편집한 첫 버전입니다. 전국 관광정보 API, 실시간 운영시간·요금, 계정과 서버 저장은 아직 연결하지 않았습니다. 장소 저장은 현재 브라우저에 한정됩니다. 방문 안내는 최신 운영시간이나 입장료를 보장하지 않으므로 별도 확인 링크를 제공합니다.

상세 벡터 타일과 고도 타일을 불러올 때 인터넷 연결이 필요합니다. 사진, Pretendard 폰트, 3D 모델, 질감, 여행 시뮬레이션과 기본 국가 경계는 로컬에 포함되어 있습니다. WebGL이 없는 브라우저에서는 지도 안내를 표시하며 여행지 목록과 상세정보는 계속 사용할 수 있습니다. 전국 지도에서의 3D 높이는 탐색 편의를 위해 1.6배로 강조하며 여행 시뮬레이션은 원래 지형 높이를 사용합니다. 지도 랜드마크는 알아보기 쉽도록 화면 크기에 맞춰 축척을 조정합니다. 가상 여행에는 WebGL 2를 지원하는 브라우저와 하드웨어 가속이 필요합니다. 맵과 게임은 동시에 실행하지 않으며 정적 모델을 재질별로 합쳐 드로 콜을 줄이고 렌더 해상도를 최대 1.5배로 제한합니다.

정적 웹 호스팅에 `dist/`를 배포할 수 있습니다. API 키나 별도 서버는 현재 필요하지 않습니다.

## 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 [GitHub Actions 워크플로](.github/workflows/pages.yml)가 테스트와 빌드를 거쳐 GitHub Pages에 배포합니다. 저장소 이름 하위 경로(`/DaeDongYeoJiDo/`)에서 열리도록 빌드할 때 `BASE_PATH`를 지정하며, 코드에서는 [`src/asset.ts`](src/asset.ts)로 `public/` 파일 경로를 만듭니다. 화면 전환은 해시 경로(`#/journey/...`)를 쓰므로 별도의 404 처리가 필요하지 않습니다.

```sh
BASE_PATH=/DaeDongYeoJiDo/ npm run build   # Pages와 같은 경로로 빌드
```
